# RestedXP Library Books

A RestedXP guide for WoW Forever that collects every library book in the fastest order and hands them in.
Alliance and Horde each get their own route, using flights, boats and the Hearthstone, ending at the librarian and
mage trainer to turn in the books and claim the Friend of the Library rewards.

Books you have already turned in are skipped. The route assumes a level 60 character on a 60% mount who knows
their faction's flight paths.

## Install

Install from CurseForge, or download a zip from [Releases](../../releases) and extract it into
`World of Warcraft/_forever_/Interface/AddOns`. Requires RestedXP Guides.

In game, open RestedXP's guide list and pick **Library Books (Alliance)** or **Library Books (Horde)** under the
*Library Books* group.
